================================================================================
                        数据助手  Data Assistant  v1.0
                              使用说明
================================================================================

【一】这是什么

数据助手是一个 Windows 桌面工具（.NET Framework 4.8），把日常最耗时的几类
重复劳动整合到一个程序里，共 4 个模块：

  1. 数据整理  —— 汇总一堆 CSV/Excel 表格，按规则清洗，再导出
  2. 数据比对  —— 两个表格按 SN 对齐，逐列比对差异并导出
  3. 图片查找  —— 按 SN 清单把图片从源目录复制到目标目录
  4. 系统优化  —— 垃圾清理、磁盘分析、启动项管理、性能调优（含网卡取相调优）

程序为单文件绿色版，不写注册表（除"控制面板→程序和功能"里的卸载项），
卸载即删干净，不留残留。


【二】安装与卸载

■ 安装（推荐用安装包）
    双击 DataAssistantSetup.exe，按向导三步走：
      第 1 页  确认安装目录（默认 C:\Program Files\DataAssistant），
               可勾选"创建桌面快捷方式"
      第 2 页  进度条 + 实时文件日志
      第 3 页  完成后可勾选"立即启动"

    安装完会有：
      · 开始菜单 → 数据助手
      · 桌面快捷方式（按你勾选的）
      · 控制面板 → 程序和功能 → "数据助手"（可从这里卸载）

■ 静默安装（给 IT 批量部署用）
    DataAssistantSetup.exe /S /dir="D:\DataAssistant"
    DataAssistantSetup.exe /S /noshortcut        ← 不建桌面快捷方式

■ 免安装直接运行
    把整个文件夹拷到任意位置，双击 DataAssistant.exe 即可，
    同目录下的 19 个 DLL 必须一起带着（缺一个会提示找不到程序集）。

■ 卸载
    ① 控制面板 → 程序和功能 → 数据助手 → 卸载
    ② 或运行安装目录下的 Uninstall.exe
    ③ 卸载会清掉：安装目录、注册表卸载项、开始菜单与桌面两个快捷方式

■ Windows 首次运行的安全提示
    安装包带自签名证书（DataAssistantSetup.cer）。若出现
    "Windows 已保护你的电脑" 蓝色窗口：
        点「更多信息」→「仍要运行」即可。
    想彻底消除提示，可双击 DataAssistantSetup.cer →「安装证书」
    → 选"受信任的根证书颁发机构"→ 完成。


【三】四个模块详解
================================================================================

■ 模块一：数据整理
--------------------------------------------------------------------------------
把散落在各文件夹里的 CSV / TXT / Excel（.xls/.xlsx）汇总成一张总表，
按你定的规则删掉脏数据，再导出去。

  操作流程：
    1) 「源文件夹」→ 选好放表格的目录，勾选"包含子文件夹"（会递归扫描）
    2) 「导出文件夹」→ 选输出位置
    3) 点「汇总」→ 所有表格合并成一张总表，原始文件名列作为溯源列
    4) 在「删除规则」分组里勾选要启用的规则（详见下表）
    5) 点「预览删除」→ 高亮出将被删掉的行，并弹窗统计每条规则各删几行
    6) 确认无误后点「应用删除」
    7) 在「筛选并导出」分组里选好关键字、筛选列、方式、格式，点「导出」
       （或直接点「导出合并总表」导出清洗后的全部数据）

  删除规则一览：
    ┌──────────────────────────────┬────────────────────────────────────┐
    │ 规则                         │ 说明                               │
    ├──────────────────────────────┼────────────────────────────────────┤
    │ 删除 SN 列为空的行           │ SN 列（序列号）为空即删            │
    │ SN列=以下占位符(逗号分隔)    │ 整格精确匹配才删，默认 SN,SN1,NOSN │
    │ 其它列含关键字(逗号分隔)     │ 命中即删，默认 999,999.999        │
    │ 关键字匹配列:                │ 指定只查某一列（空=查所有其它列）  │
    │ 删除 SN 重复的行              │ 重复的 SN 只留一条                │
    └──────────────────────────────┴────────────────────────────────────┘

    ★ 重要提示：
      · 「SN列=以下占位符」是整格精确匹配（忽略大小写），填 SN1 不会误删 SN12345
      · 「其它列含关键字」是子串匹配。若填 999，它会扫描所有非 SN 列，
        时间戳、编号里带 999 的正常数据会被误删 —— 所以务必用「关键字匹配列」
        限定到具体那一列（例如 StationID），这是最安全的用法
      · 关键字一律用英文逗号分隔；只有「方式」选「正则」时整框才当单个正则
      · 「方式」选 包含/等于/开头 时，逗号分隔的每个值都会各自匹配
      · 「删除 SN 重复的行」默认保留第一条，可下拉改为保留末条；
        空 SN 不参与去重（归「空 SN」规则管）

  筛选并导出：
    ┌──────────────┬──────────────────────────────────────────────────┐
    │ 关键字       │ 逗号分隔；留空 = 导出全部                           │
    │ 筛选列       │ 任意列 / 指定列名（下拉，汇总后自动填充所有列名） │
    │ 方式         │ 包含 / 等于 / 开头 / 正则                          │
    │ 首行是表头   │ 勾上则首行当列名，不当数据                        │
    │ 格式         │ CSV（UTF-8 BOM，Excel 直接打开不乱码）/ Excel     │
    │ 导出方式     │ 按原始文件分别导出 / 导出合并总表                 │
    └──────────────┴──────────────────────────────────────────────────┘

    · 「导出清洗结果」= 一键完成 汇总 → 应用删除规则 → 导出，不用先点"应用删除"
    · 「按原始文件分别导出」会把清洗后的数据按来源文件拆开，各写一个文件


■ 模块二：数据比对
--------------------------------------------------------------------------------
两个不同的表格，以表 A 的 SN 顺序为主轴，去表 B 里找同一个 SN，
逐列比对值有没有差异，结果可导出。

  操作流程：
    1) ① 表格A：选文件 → 选 SN 列 → 勾选要比的列（可多选）
    2) ② 表格B：选文件 → 选 SN 列 → 勾选要比的列（可多选）
    3) ③ 比对方式与导出：
         配对方式  ├ 按列名配对：两边列名相同自动配成一对
                   └ 按勾选顺序：按你在两边勾选的先后顺序一一对应
         配对预览  实时显示配对关系，确认没配错
         比对方式  ├ 文本精确：完全相同才算一致
                   ├ 数值比较：按数值比，可填容差（如 0.001）
                   └ 包含比较：B 的值包含 A 的值即算一致
         忽略大小写  勾上后 PASS 与 pass 视为相同
         容差        仅"数值比较"有效，默认 0.000001
    4) 点「开始比对」
    5) 结果表里：绿色=一致，红色=不一致，橙色=缺失
       勾「只看差异行」可过滤掉一致的行
       差异明细会逐行列在下方日志里（最多 20 行）
    6) 点「导出比对结果」

  结果表只显示 SN + 你勾选的列（序号/结果/说明是内部用的，已隐藏）

  未匹配行的处理：
    · 默认不输出（只在 A 有、只在 B 有的行都不出现在结果里）
    · 勾「输出未匹配行」才会输出
    · 勾「包含表B多出的SN」→ 表 B 里 A 没有的 SN 也会追加到结果末尾
    · 序号保留的是该行在表 A 中的原始位置，所以剔除后会跳号（如 1,2,4），
      便于回溯原表

  ·「A / B 互换」按钮可对调两边，快速换个方向再比一次
  · 文本比对前会统一去掉首尾空格
  · 数值比较先按不变文化解析，失败再按当前区域解析


■ 模块三：图片查找
--------------------------------------------------------------------------------
按 SN 清单，把图片从源目录批量复制到目标目录（按 SN 建子文件夹）。

  操作流程：
    1) 「SN 文件」→ 选一份清单（每行一个 SN）
       · 勾「首行是表头(按列名 SN 取, 否则取第一列)」
         → 按列名 "SN" 取该列；不勾则取第一列
    2) 「源文件夹」→ 图片所在目录
    3) 「导出文件夹」→ 复制到哪里
    4) 点「扫描预览」→ 列出每个 SN 匹配到几张图片，先核对再复制
    5) 点「开始复制」

  · 勾「包含子文件夹」会递归查找源目录下的所有子目录
  · 预览表里能看到每个 SN 对应的图片文件列表


■ 模块四：系统优化
--------------------------------------------------------------------------------
含 8 个子页签。程序会自动请求管理员权限；用户取消 UAC 则降级运行
（系统目录清理、HKLM 启动项修改会跳过，其余功能正常）。

  ┌────────────┬────────────────────────────────────────────────────────┐
  │ 垃圾清理   │ 扫描并清理临时文件、浏览器缓存、AI 工具垃圾、系统日志 │
  │            │ 等 45 个目标点。只删文件保留目录；权限不足的逐个跳过。  │
  │            │ ★ 清理前会二次确认，且不进回收站 —— 无法撤销        │
  ├────────────┼────────────────────────────────────────────────────────┤
  │ 磁盘分析   │ 各盘容量占用、目录体积排行，找空间黑洞                │
  ├────────────┼────────────────────────────────────────────────────────┤
  │ 启动项管理 │ 列出开机自启项（注册表 Run/RunOnce + 启动文件夹）      │
  │            │ 可启用/禁用。禁用 = 搬到备份键，不丢数据，可完整还原   │
  ├────────────┼────────────────────────────────────────────────────────┤
  │ 性能优化   │ 释放内存、清空工作集、开关窗口动画等即时优化项        │
  ├────────────┼────────────────────────────────────────────────────────┤
  │ 系统优化项 │ 25 项系统设置勾选（服务、注册表、隐私强化等）         │
  │            │ ★ 所有改动写入前自动备份原值，「一键还原」可全部回滚 │
  ├────────────┼────────────────────────────────────────────────────────┤
  │ 重复文件   │ MD5 查重。路径最短/最早的一个保留，其余勾选为可删    │
  │            │ ★ 请人工核对后再删除                                │
  ├────────────┼────────────────────────────────────────────────────────┤
  │ 路径配置   │ 用户库迁移、AI 产出重定向根目录、AI 垃圾清理路径清单  │
  ├────────────┼────────────────────────────────────────────────────────┤
  │ 网络与取相 │ Cognex《"取相非正常失败"》对策，10 个网卡调优项：    │
  │            │ 巨帧 9014、关闭节能以太网、接收缓冲区取最大、         │
  │            │ USB 选择性暂停→禁用、PCIe 链接状态→禁用 等            │
  │            │ ★ 橙色「需人工处理」提示的是 BIOS/接线，程序改不了    │
  └────────────┴────────────────────────────────────────────────────────┘

  ★★ 系统优化的安全机制 ★★
    · 「系统优化项」里所有对注册表/服务的改动，写入前都会备份原值
      （含"原本就不存在"这个事实本身）
    · 备份文件：%APPDATA%\DataAssistant\OptimizerBackup\registry_backup.txt
    · 点「一键还原」即可全部回滚
    · 禁用启动项时，值会搬到注册表备份键
      HKCU/HKLM\Software\DataAssistant\DisabledStartup，可完整还原
    · 关掉「包含表B多出的SN」等选项不影响还原功能

  ★ 提权相关
    · 程序启动时会弹 UAC 要管理员权限，这是为了清理系统目录和改 HKLM
    · 程序内还带「以管理员身份重新运行」的自提权逻辑（自动处理，
      且先释放单实例互斥量，避免提权后的新进程误判"已在运行"）
    · 未以管理员身份运行时，会明确提示哪些功能被跳过


【四】界面设置自动保存
--------------------------------------------------------------------------------
  程序会记住你的操作习惯，下次打开直接是上次的设置，不用重新勾一遍。

  ■ 会保存的（参数类）
    数据整理页
      · 删除规则：4 个规则勾选（空SN / SN重复 / 占位符 / 其它列关键字）
      · 重复 SN 保留「首条 / 末条」
      · SN 占位符列表、其它列关键字列表
      · 关键字匹配列、SN 列（汇总后自动套用）
      · 筛选关键字、筛选列、匹配方式（包含/等于/开头/正则）
      · 「按原始文件分别导出」「导出合并总表」、导出格式（CSV/Excel）
      · 「包含子文件夹」「首行是表头」

    数据比对页
      · 配对方式、比对方式（文本精确/数值比较/包含比较）
      · 忽略大小写、数值容差
      · 「包含表B多出的SN」「输出未匹配行」「只看差异行」「首行是表头」
      · 导出格式
      · 表格A/B 的 SN 列选择、勾选要比对的列（连勾选先后顺序一起记）

    图片查找页
      · 「首行是表头(按列名 SN 取, 否则取第一列)」

    系统优化页
      · 「系统优化项」25 个优化项的勾选状态
      · 「网络与取相」10 个网卡调优项的勾选状态
      · 「重复文件」页的扫描目录

  ■ 不会保存的
    · 所有文件/文件夹路径（数据文件夹、导出文件夹、表格文件、源/目标目录…）
      —— 路径与当次任务强相关，记住旧路径反而容易误操作到过期目录，
         所以每次启动都是空的，由你自己选一次。
    · 启动项管理里的启用/禁用状态 —— 那是运行时操作，禁用项有备份键可还原，
      不需要靠配置文件记。
    · 汇总后的数据、比对结果、扫描结果 —— 这些是任务产物，不是设置。

  ■ 保存时机
      · 正常关闭程序时（点右上角关闭按钮 / Alt+F4）
      · 每 60 秒自动保存一次（兜底：万一被任务管理器强杀，最多丢 1 分钟内的改动）

  ■ 配置文件位置与格式
      默认保存在程序（DataAssistant.exe）所在的启动目录：
          <启动目录>\settings.xml
      若启动目录不可写（例如装在 Program Files 且未以管理员运行），
      则自动改存到：
          %APPDATA%\DataAssistant\settings.xml

      格式：XML（UTF-8），可读可手工编辑，按面板分节：
          <Section name="数据整理">
            <Item key="Header" value="1" />
            <List name="ColsA"><Value>SN</Value></List>
          </Section>
      （文件损坏时程序会静默忽略并用默认值启动，不会崩。）

  ★ 删掉这个文件就等于恢复出厂设置（所有参数回到初始值）。
  ★ 从旧版升级：首次启动会自动把旧的 ui_settings.cfg（base64）导入并改名为
    ui_settings.cfg.bak，原设置不会丢。


【五】配置文件位置（系统优化相关）
--------------------------------------------------------------------------------
  %APPDATA%\DataAssistant\
    ├─ settings.xml                 界面设置（见上一节）
    ├─ optimizer.cfg                系统优化配置（base64 编码，勿手工改）
    └─ OptimizerBackup\
         └─ registry_backup.txt      注册表改动备份，供「一键还原」使用

  从旧版本（EasyFindImageTool）升级时，程序会自动把这些文件搬到新目录，
  你的配置和还原点不会丢。


【六】常见问题
--------------------------------------------------------------------------------
  Q: 找不到 NPOI / 某个 DLL ？
  A: 绿色版必须整个文件夹一起拷贝，别只拿 DataAssistant.exe。
     缺 DLL 时程序会提示"找不到程序集"。

  Q: 我改了设置，怎么下次打开又变回原来的了？
  A: 检查 %APPDATA%\DataAssistant\settings.xml 是否存在且可写。
     另外「按原始文件分别导出 / 导出合并总表」「A表/B表勾选的列」
     这类与汇总/表格内容相关的设置，要先做一次汇总或载入表格才会有值。
     如果你换了台电脑或清了 %APPDATA%，设置自然不会跟过去。

  Q: 点了删除，数据全没了？
  A: 先点「预览删除」看统计。常见原因：「其它列含关键字」填了 999，
     而时间戳/编号里含 999 的正常行被误删。把「关键字匹配列」指定到
     具体列（如 StationID）就能避免。误删无法撤销，请先备份。

  Q: 数据比对提示"没有可配对的列"？
  A: 按列名配对要求两边列名完全一致；按顺序配对要求两边都至少勾一列。
     看「配对预览」确认。

  Q: 比对结果说"不一致"，但值看着一样？
  A: 检查是否多选了"忽略大小写"，以及数值模式下容差是否过小。

  Q: 系统优化某些项没生效？
  A: 大概率是没用管理员权限运行。程序会弹 UAC，请点"是"。

  Q: 卸载后还剩点东西？
  A: 卸载会清目录、注册表项、两个快捷方式。若程序当时正在运行，
     文件被占用会删不掉 —— 关掉程序后重跑 Uninstall.exe 即可。

  Q: 安装包被 Windows 拦下（"Windows 已保护你的电脑"）？
  A: 点「更多信息」→「仍要运行」。或先双击 DataAssistantSetup.cer
     安装证书（受信任根）再运行，就不会再提示。

  Q: 能同时开两个程序吗？
  A: 不能。程序有单实例保护，重复启动会提示"数据助手已在运行"。
