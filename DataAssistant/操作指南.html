数据助手 DataAssistant · 操作指南

把日常最耗时的重复劳动整合到一个程序里：数据整理、数据比对、图片查找、系统优化，外加无人值守的定时备份与定时删图。

版本 v1.1.0 .NET Framework 4.8 Windows 7 / 10 / 11 绿色单文件 · 自带依赖

1概览

本程序包含 6 个功能模块，通过顶部标签页切换：

① 数据整理汇总一堆 CSV/TXT/Excel，按规则清洗，再导出
② 数据比对两个表格按 SN 对齐，逐列比对差异并导出
③ 图片查找按 SN 清单把图片从源目录复制到目标目录
④ 系统优化垃圾清理、磁盘分析、启动项、性能与网卡调优
⑤ 定时自动备份按天/周/月周期自动备份文件夹，超限自动清理
⑥ 定时自动删图最多 10 个任务，按天清理超龄图片文件夹
运行时三件事
  • 配置文件保存在程序启动目录：<启动目录>\settings.xml（不可写时自动改存 %APPDATA%\DataAssistant\）
  • 日志文件保存在程序启动目录：<启动目录>\Log\log_YYYY-MM-DD.txt（按天滚动）
  • 托盘常驻：点窗口右上角 X 只是最小化到托盘，进程继续后台执行定时任务

2安装与卸载

安装（推荐用安装包）

  1. 双击 DataAssistantSetup.exe，第一页确认安装目录（默认 C:\Program Files\DataAssistant），可勾选「创建桌面快捷方式」
  2. 第二页显示进度条与实时文件日志
  3. 第三页完成后可勾选「立即启动」

安装完后会得到：开始菜单 → 数据助手；桌面快捷方式（按你勾选）；控制面板 → 程序和功能 →「数据助手」（可卸载）。

静默安装（IT 批量部署）

DataAssistantSetup.exe /S /dir="D:\DataAssistant"
DataAssistantSetup.exe /S /noshortcut      ← 不建桌面快捷方式

免安装直接运行

把整个文件夹拷到任意位置，双击 DataAssistant.exe 即可。同目录下的 DLL 必须一起带着（缺一个会提示找不到程序集）。

卸载

  • 控制面板 → 程序和功能 → 数据助手 → 卸载
  • 或运行安装目录下的 Uninstall.exe
  • 卸载会清掉：安装目录、注册表卸载项、开始菜单与桌面快捷方式

Windows 首次运行的安全提示

遇到「Windows 已保护你的电脑」
点「更多信息」→「仍要运行」即可。想彻底消除提示，双击随包的 DataAssistantSetup.cer →「安装证书」→ 选择「受信任的根证书颁发机构」→ 完成。

3托盘与生命周期

操作结果
点击窗口右上角 X / Alt+F4最小化到托盘，进程不退出，定时任务照常执行
双击托盘图标重新显示主窗口（前台）
右键托盘图标 → 显示主界面同上，打开主窗口
右键托盘图标 → 退出真正结束进程（唯一的退出方式）
设计意图关闭窗口 ≠ 退出。只有右键菜单的「退出」才会保存设置并结束进程，避免误关窗口导致定时任务中断。

开机启动

在「定时自动备份」页勾选「开机启动并最小化到托盘」。程序优先通过任务计划程序注册（静默、不弹 UAC），失败自动回退到注册表 HKCU Run 键；登录后会以 /tray 模式后台静默启动。

右下角时钟

主窗口底部状态栏右侧实时显示当前日期、星期、时间，每秒刷新，同时显示任务状态（如「正在备份中…」）。

4模块一：数据整理

把散落在各文件夹里的 CSV / TXT / Excel（.xls/.xlsx）汇总成一张总表，按规则删掉脏数据，再导出。

操作流程

  1. 「源文件夹」→ 选放表格的目录，勾选「包含子文件夹」（递归扫描）
  2. 「导出文件夹」→ 选输出位置
  3. 点「汇总」→ 所有表格合并成一张总表，原始文件名作为溯源列
  4. 在「删除规则」分组里勾选要启用的规则（见下表）
  5. 点「预览删除」→ 高亮将被删掉的行，并弹窗统计每条规则删了几行
  6. 确认无误后点「应用删除」
  7. 在「筛选并导出」分组里选关键字、筛选列、方式、格式，点「导出」；
    或直接点「导出清洗结果」一键导出清洗后的合并总表

删除规则一览

规则说明
删除 SN 列为空的行SN 列（序列号）为空即删
SN 列 = 以下占位符整格精确匹配才删，默认 SN,SN1,NOSN
其它列含关键字子串匹配，命中即删，默认 999,999.999
关键字匹配列指定只查某一列（留空 = 查所有其它列）
删除 SN 重复的行重复 SN 只留一条（默认留首条，可改末条）
最易踩的坑
  • 「其它列含关键字」是子串匹配。填 999 会扫描所有非 SN 列，时间戳、编号里带 999 的正常数据会被误删
  • 务必用「关键字匹配列」限定到具体那一列（例如 StationID），这是最安全的用法
  • 删除不可撤销 —— 先用「预览删除」核对统计，必要时先备份原表

匹配规则补充

  • 关键字一律用英文逗号分隔；只有「方式」选「正则」时整框才当单个正则
  • 「方式」选 包含 / 等于 / 开头 时，逗号分隔的每个值都会各自匹配
  • 空 SN 不参与去重（归「空 SN」规则管）

筛选并导出

项说明
关键字逗号分隔；留空 = 导出全部
筛选列任意列 / 指定列名（下拉，汇总后自动填充）
方式包含 / 等于 / 开头 / 正则
首行是表头勾上则首行当列名，不当数据
格式CSV（UTF-8 BOM，Excel 直接打开不乱码）/ Excel
导出方式按原始文件分别导出 / 导出合并总表（只对「筛选并导出」生效）
两个按钮的区别
  • 导出清洗结果 = 一键完成「汇总 → 应用删除规则 → 只导出合并总表」，无需先点「应用删除」，且不受「按原始文件分别导出」勾选影响
  • 筛选并导出 = 尊重两个勾选框；想按来源文件拆分成多个文件，走这里

5模块二：数据比对

两个不同表格，以表 A 的 SN 顺序为主轴，去表 B 找同一个 SN，逐列比对值有无差异，结果可导出。

操作流程

  1. ① 表格 A：选文件 → 选 SN 列 → 勾选要比的列（可多选）
  2. ② 表格 B：选文件 → 选 SN 列 → 勾选要比的列（可多选）
  3. ③ 设置比对方式与导出：
    · 配对方式：按列名配对（列名相同自动成对）/ 按勾选顺序（按勾选先后一一对应）
    · 配对预览：实时显示配对关系，确认没配错
    · 比对方式：文本精确 / 数值比较（可填容差，如 0.001）/ 包含比较
    · 忽略大小写：勾上后 PASS 与 pass 视为相同
    · 容差：仅数值比较有效，默认 0.000001
  4. 点「开始比对」
  5. 结果表：绿色=一致　红色=不一致　橙色=缺失；勾「只看差异行」可过滤；差异明细逐行列在下方日志（最多 20 行）
  6. 点「导出比对结果」

未匹配行的处理

  • 默认不输出（只在 A 有 / 只在 B 有的行都不出现在结果里）
  • 勾「输出未匹配行」才会输出
  • 勾「包含表 B 多出的 SN」→ 表 B 里 A 没有的 SN 追加到结果末尾
  • 序号保留该行在表 A 中的原始位置，剔除后会跳号（如 1、2、4），便于回溯原表

其它细节：「A / B 互换」按钮可对调两边快速换个方向再比；文本比对前统一去掉首尾空格；数值比较先按不变文化解析，失败再按当前区域解析。

6模块三：图片查找

按 SN 清单，把图片从源目录批量复制到目标目录（按 SN 建子文件夹）。

操作流程

  1. 「SN 文件」→ 选一份清单（每行一个 SN）。勾「首行是表头」则按列名 SN 取该列，不勾则取第一列
  2. 「源文件夹」→ 图片所在目录
  3. 「导出文件夹」→ 复制到哪里
  4. 点「扫描预览」→ 列出每个 SN 匹配到几张图片，先核对再复制
  5. 在「图片格式」区勾选要复制的格式，点「开始复制」

关键行为

项行为
可选格式JPG / PNG / BMP 三项，默认全选；JPG 项同时包含 .jpg 与 .jpeg
一个都不勾不复制任何图片，且不会残留空文件夹
SN 重复同一 SN 命中多个同名文件夹时，只复制创建时间最早的那一个，其余忽略并在日志注明
中途取消复制/扫描进行中，再次点击该按钮即变为「取消」，可随时中断（每复制一个文件就检查一次取消信号）
包含子文件夹递归查找源目录下的所有子目录
建议大批量复制前先跑一次「扫描预览」，确认命中数与路径无误，再执行复制，可省去反复试错的时间。

7模块四：系统优化

含 8 个子页签。程序会自动请求管理员权限；用户取消 UAC 则降级运行（系统目录清理、HKLM 启动项修改会跳过，其余正常）。

子页签说明
垃圾清理扫描清理临时文件、浏览器缓存、AI 工具垃圾、系统日志等 45 个目标点。只删文件保留目录，权限不足逐个跳过
磁盘分析各盘容量占用、目录体积排行，找空间黑洞
启动项管理列出开机自启项（注册表 Run/RunOnce + 启动文件夹），可启用/禁用
性能优化释放内存、清空工作集、开关窗口动画等即时优化项
系统优化项25 项系统设置勾选（服务、注册表、隐私强化等）
重复文件MD5 查重，路径最短/最早的一个保留，其余勾选为可删
路径配置用户库迁移、AI 产出重定向根目录、AI 垃圾清理路径清单
网络与取相Cognex《取相非正常失败》对策，10 个网卡调优项（巨帧 9014、关闭节能以太网、接收缓冲区取最大、禁用 USB 选择性暂停、禁用 PCIe 链接状态等）
不可逆操作
  • 垃圾清理：清理前二次确认，不进回收站，无法撤销
  • 重复文件删除：请人工核对后再删
  • 橙色「需人工处理」提示的是 BIOS / 接线问题，程序改不了，需手动处理
安全机制（可回滚）
  • 「系统优化项」所有注册表/服务改动，写入前自动备份原值（含「原本就不存在」这个事实本身）
  • 备份文件：%APPDATA%\DataAssistant\OptimizerBackup\registry_backup.txt，点「一键还原」全部回滚
  • 禁用启动项时，值搬到备份键 HKCU/HKLM\Software\DataAssistant\DisabledStartup，可完整还原

提权相关

  • 启动时会弹 UAC 要管理员权限（为了清理系统目录和改 HKLM）
  • 程序内带「以管理员身份重新运行」自提权逻辑，自动处理，且先释放单实例互斥量，避免新进程误判「已在运行」
  • 未以管理员身份运行时，会明确提示哪些功能被跳过

8模块五：定时自动备份

把指定的「源文件夹」按设置的周期自动复制到「备份路径\YYYYMMDD」下，完成后按保留个数清理最旧的备份。

配置步骤

  1. 勾选「启用定时自动备份」
  2. 「源路径」= 要备份的文件夹（整个目录，含子目录）→ 点「选择目录」
  3. 「备份路径」= 备份存放根目录（内部按日期自动建 YYYYMMDD 子文件夹）
  4. 「备份周期」= 每天 / 每周 / 每月（每周≈每 7 天，每月≈每 30 天触发）
  5. 「备份时间」= 每天该时刻开始备份（HH:mm，24 小时制）
  6. 「保留个数」= 只保留最近 N 个日期文件夹，超出的最旧备份自动删除
  7. 勾选「开机启动并最小化到托盘」→ 登录后自动后台运行

执行行为

  • 到达周期的备份时刻触发；备份过程在后台线程执行，不卡界面、不影响其它软件运行
  • 状态栏显示「正在备份中…」；完成后显示「上次备份：日期时间」
  • 备份完成后立即检查保留个数，删掉超出的最旧备份
  • 全过程记录在运行日志页
注意源路径不存在时任务会跳过并记录日志，不会报错干扰。首次使用建议把「备份时间」设成几分钟后，验证一次生成结果是否符合预期。

9模块六：定时自动删图

每天在设定时刻，删除指定路径下「创建时间」超过保留天数的子文件夹（整个文件夹一起删）。最多可设 10 个任务。

配置步骤

  1. 点「添加任务」（最多 10 个）
  2. 每行填：
    · 路径：点该行「浏览」列的「选择」按钮挑选目录，也可直接双击「路径」列手填（该目录的下一级子文件夹会被判断年龄）
    · 删除时间：HH:mm，每天该时刻触发一次
    · 保留天数：文件夹创建时间距今超过该天数即删除
    · 启用：是否参与定时执行
  3. 选中行后点「删除选中」可移除任务
删除是永久的、不可恢复 请务必确认路径填写正确。删除动作在后台线程执行，不卡界面；所有动作记录在运行日志与日志文件。
与常规路径规则的例外 其它模块的文件路径不保存（避免误操作过期目录），但定时备份与定时删图的路径会被保存 —— 定时任务本身就是要求记住路径的。

11设置保存与配置

程序会记住你的操作习惯，下次打开直接是上次的设置，不用重新勾一遍。

会保存的（参数类）

面板保存内容
数据整理17 项：4 个删除规则勾选、重复 SN 保留首条/末条、占位符与关键字列表、关键字匹配列、SN 列、筛选关键字/列/方式、导出格式、导出方式、包含子文件夹、首行是表头
数据比对11 项 + 2 列表：配对方式、比对方式、忽略大小写、容差、包含表 B 多出的 SN、输出未匹配行、只看差异行、首行是表头、导出格式、A/B 的 SN 列与勾选列（连勾选先后顺序一起记）
图片查找首行是表头、勾选的图片格式（JPG/PNG/BMP）
系统优化25 个系统优化项勾选 + 10 个网卡调优项勾选 + 重复文件扫描目录
定时备份启用、源路径、备份路径、周期、时间、保留个数、开机启动
定时删图全部任务行（路径、删除时间、保留天数、启用）

不会保存的

  • 普通模块的文件/文件夹路径（数据文件夹、导出文件夹、表格文件、源/目标目录） —— 路径与当次任务强相关，记住旧路径容易误操作到过期目录，所以每次启动都是空的，由你选一次
  • 启动项管理里的启用/禁用状态 —— 运行时操作，有备份键可还原
  • 汇总后的数据、比对结果、扫描结果 —— 任务产物，不是设置

保存时机

  • 通过托盘右键「退出」正常关闭时
  • 每 60 秒自动保存一次（兜底：万一被强杀，最多丢 1 分钟内的改动）

配置文件位置与格式

<启动目录>\settings.xml
启动目录不可写时：%APPDATA%\DataAssistant\settings.xml

XML（UTF-8），可读可手工编辑，按面板分节：

<?xml version="1.0" encoding="utf-8"?>
<Settings>
  <Section name="AutoBackup">
    <Item key="Enabled" value="1" />
    <Item key="Source" value="D:\Cognex\Vision" />
    <Item key="Keep" value="7" />
  </Section>
  <Section name="AutoDelete">
    <List name="Tasks">
      <Value>D:\Data\Wip|03:00|30|1|</Value>
    </List>
  </Section>
</Settings>
小贴士
  • 删掉 settings.xml = 恢复出厂设置（所有参数回初始值，定时任务需重设）
  • 文件损坏时程序会静默忽略并用默认值启动，不会崩
  • 值里的中文、竖线、逗号、等号都会正确转义，无解析歧义
  • 从旧版升级：首次启动自动导入旧的 ui_settings.cfg（base64）并改名为 ui_settings.cfg.bak，原设置不丢

12常见问题

问题解决办法
找不到 NPOI / 某个 DLL？绿色版必须整个文件夹一起拷贝，别只拿 DataAssistant.exe。缺 DLL 时会提示「找不到程序集」
改了设置，下次打开又变回原来？检查 <启动目录>\settings.xml 是否存在且可写。另外「导出勾选列」这类与表格内容相关的设置，要先做一次汇总或载入表格才会有值
点了删除，数据全没了？先点「预览删除」看统计。常见原因：「其它列含关键字」填了 999，时间戳/编号里含 999 的正常行被误删 —— 用「关键字匹配列」限定到具体列
数据比对提示「没有可配对的列」？按列名配对要求两边列名完全一致；按顺序配对要求两边都至少勾一列。看「配对预览」确认
比对说「不一致」但值看着一样？检查是否漏勾「忽略大小写」，以及数值模式下容差是否过小
图片复制没停 / 点取消没反应？进行中再次点击原按钮即变为「取消」（v1.1 起每个文件复制后都会检查取消信号，立即中断）
同一 SN 复制了多个文件夹？v1.1 起只复制「创建时间最早」的那一个同名文件夹
定时任务没执行？① 确认勾选「启用」② 确认托盘进程在跑（右键退出后就不会执行）③ 看运行日志里的触发记录
日志文件在哪？程序启动目录下 Log\log_YYYY-MM-DD.txt
系统优化某些项没生效？大概率没用管理员权限运行。请允许 UAC 弹窗
卸载后还剩点东西？程序正在运行时文件被占用会删不掉 —— 右键托盘「退出」后重跑 Uninstall.exe
能同时开两个程序吗？不能。有单实例保护，重复启动会提示「数据助手已在运行」
